# Eight-in-a-Row Go · 八子连珠围棋

基于 HapHac/weiqi 的本地双人棋类实验：沿用围棋的气、提子和简单打劫判断，增加八颗及以上同色棋子连线获胜规则。支持 9 / 13 / 19 路棋盘、弃手、重开和原版悔棋机制。

## 运行

Python 3.9+，安装包含 Tkinter 的 Python。Linux 可能需系统包 python3-tk。

```sh
python3 index.py
python3 -m unittest discover -s tests -v
```

资源相对程序文件定位，可从任意工作目录启动。游戏没有 AI 对手、联网或棋谱存档。
